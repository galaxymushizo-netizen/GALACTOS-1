# GALACTOS-1

Health mobile tracking app — ya kwanza kutoka Galaxy. Built with Kotlin na Google Gemini AI.

## Vipengele

- Health tracking na monitoring
- AI-powered insights na Gemini
- Android native app (Kotlin)
- Data visualization ya health metrics

## Quick Start

1. Open Android Studio
2. Select **Open** and choose the project directory
3. Allow Android Studio to fix any incompatibilities
4. Create `.env` file and set `GEMINI_API_KEY` (see `.env.example`)
5. Build and run on your device/emulator

## Tech Stack

- Kotlin
- Android SDK
- Google Gemini AI
- Gradle

## Prerequisites

- Android Studio
- Gemini API key
- Android device or emulator
